# Khmer All Fonts

A curated collection of Khmer Unicode and multilingual font files for design, documentation, localization, and testing.

This repository includes a broad set of fonts in formats such as `.ttf`, `.otf`, and legacy `.fon` files, with a focus on Khmer script support and general multilingual typography.

## Overview

The project is organized to make it easy to browse, preview, and install fonts locally on Windows systems. It is especially useful for:

- Khmer-language interfaces and documents
- Typography experiments and design mockups
- Web and app localization testing
- Font comparison and selection workflows
- Offline access to a large font collection

## Included Fonts

The collection contains a wide range of fonts, including:

- Khmer Unicode fonts
- Khmer display and decorative fonts
- Latin and multilingual fonts
- Legacy system fonts
- OpenType and TrueType font families

## Installation (Windows)

1. Open the `All Fonts` folder.
2. Double-click any font file you want to install.
3. Click Install or Install for all users.
4. Open applications such as Word, PowerPoint, Photoshop, or design tools to preview and use them.

You can also install multiple files by selecting several fonts and choosing Install.

## Preview and Use

To preview the fonts:

- Open Microsoft Word or PowerPoint
- Select the font in the font list
- Type Khmer sample text such as:

```text
សួស្តី! នេះគឺជាបណ្ដុំពុម្ពអក្សរខ្មែរ
```
